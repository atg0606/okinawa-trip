# 오키나와 가족여행 2026

## 파일
- `index.html`: 기존 일정과 디자인을 유지하고 준비물 체크·자동 저장, 바로가기, 이동 정보 입력을 추가한 여행 페이지
- `.nojekyll`: 별도 변환 없이 정적 파일 제공

## 열기
`index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.
페이지 스타일은 HTML에 포함되어 있으며, 지도 링크를 열 때는 인터넷 연결이 필요합니다.

## GitHub Pages 배포
1. 이 폴더 안의 파일을 GitHub 저장소 최상위에 업로드합니다.
2. 저장소 Settings → Pages에서 Deploy from a branch를 선택합니다.
3. 파일을 올린 브랜치와 /(root)를 선택해 저장합니다.
4. 배포가 완료되면 Pages에 표시되는 주소로 접속합니다.

ZIP 자체가 아닌 압축을 푼 파일을 업로드하세요. 저장소 하위 폴더가 아닌 최상위에 index.html이 있어야 합니다.

## 점검 결과
- 기존 여행 일정과 디자인 유지, 준비물은 체크 가능한 목록으로 변경
- 외부 스타일·스크립트·이미지 파일 의존성 없음
- 로컬 경로나 사이트 루트 기준 파일 참조 없음
- 지도는 기존 HTTPS 링크 유지
- 여행지 영업시간, 예약 정보, 지도 목적지 정확성은 이번 파일 점검 범위에 포함되지 않음

## 입력 정보 저장
준비물 체크와 숙소·이동 정보는 현재 브라우저의 localStorage에 저장됩니다. 다른 기기나 브라우저와 동기화되지 않습니다. 로컬 파일과 배포된 사이트의 저장 공간도 다릅니다. 브라우저 데이터 삭제 시 저장 정보가 지워질 수 있습니다. 저장이 차단되면 화면에 안내가 표시됩니다.
